# 한해 달력

공휴일·24절기·세시풍속과 내 구글 캘린더 일정을 **한 해 단위로 한눈에** 보는 달력 앱.

👉 **열기: https://leekangeun0120.github.io/yearcal/**

## 폰에 앱처럼 설치하기
- 아이폰: 사파리로 위 주소 → 공유 버튼 → **홈 화면에 추가**
- 안드로이드: 크롬으로 위 주소 → ⋮ 메뉴 → **앱 설치 / 홈 화면에 추가**

## 데이터
- 공휴일: 구글 「대한민국의 휴일」 캘린더
- 절기: 태양 황경 계산(한국 표준시) · 세시: 음력 기준(정월대보름·한식·단오·삼복·칠석·백중·중양절)
- 내 일정: 암호화(AES-GCM)되어 올라가며, 비밀 문구를 넣은 기기에서만 보인다.
